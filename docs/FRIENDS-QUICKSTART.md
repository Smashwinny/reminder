# 拾遗：小范围朋友试用说明

## 安装与登录

- 手机使用正式签名 APK 2.3.5（versionCode 22），由维护者单独发送。已有安装应覆盖升级，不要卸载或清除应用数据。
- 电脑打开 https://reminder.geniusqi.com 。手机和电脑使用同一用户名、密码。
- 首次注册需要维护者私下给的邀请码，用户名 3–32 位，密码 8–128 位。不要共享账号、密码或把邀请码公开发群。
- 忘记密码请联系维护者生成一次性重置链接，不要重新注册同名账号来“恢复数据”。

## 使用与确认

- 粘贴文字或链接后记录；切换设备前确认同步完成，并在另一端实际看到任务。
- 同步失败时保留本地数据，不要卸载、清缓存或反复注册。截图错误提示和发生时间交给维护者，不发送密码/令牌。
- 通知权限必须开启；系统节电可能延迟提醒，不适合必须准点的紧急事项。
- 电脑页面加载后可先显示本地缓存，但不支持完全断网时首次打开网页。清浏览器站点数据会清除未上传缓存。
- 图片/视频目前只同步任务描述，本地附件文件不会自动传到电脑。

## 隐私与额度边界

- 不同账号在应用层隔离，但这不是端到端加密：服务器管理员及基础设施存在访问数据的技术边界。
- 链接摘要会由服务器读取公开网页，并把网页内容交给 Kimi 生成摘要。不要把需要保密的内部链接、带访问令牌的链接或敏感内容当作匿名资料提交。
- 默认每账号每天最多 20 次 AI 请求，全站 200 次，失败重试也计数；按 UTC 日切换（北京时间 08:00）。额度不足不影响保存任务。
- 目前有云端每日备份和维护者电脑每小时拉取/验证；维护者电脑关机时，不执行异机检查和桌面告警。不能承诺零故障、零数据损失。

## 维护者交付前检查

- 给朋友的必须是正式签名 `app/build/outputs/apk/release/app-release.apk`，不要分发 debug 包或密钥目录。
- 运行 `node --test sync-server/*.test.js`；实际公网账号流程用 `node deploy/verify-friend-flow.js`，其测试账号会保留用于复验，不直接改生产数据库清理。
- 查看 `systemctl --user status reminder-offsite-check.timer` 和 `backups/offsite/status.json`；敏感备份和测试凭据不要提交 Git 或发朋友。
- 云端唯一生产实例是阿里云 `/opt/reminder` 的 `reminder_app`。不要启动本机旧隧道来排查公网故障。
- 本轮完整证据与未完成事项见 `docs/RELEASE-SAFETY-20260908.md`。此说明不代表已批准全量 OTA 或公开推广。

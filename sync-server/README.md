# 渐明电脑同步端

无需安装依赖，电脑已安装 Node.js 即可运行：

```bash
SYNC_CODE=你自己的同步码 node sync-server/server.js
```

默认端口是 `8787`，默认同步码是 `123456`。电脑浏览器打开：

```text
http://localhost:8787
```

手机和电脑连接同一网络后，在手机 App 顶部点击“同步”，填写：

- 电脑地址：`http://电脑局域网IP:8787`
- 同步码：启动服务时使用的 `SYNC_CODE`

数据保存在 `sync-server/data/tasks.json`，该目录已加入 `.gitignore`。

## 限制

这是用于尽快验证产品流程的局域网版本：电脑关闭或离开同一网络时，手机仍可离线记录，但需要下次连接电脑后手动同步。同步码只是局域网内的轻量保护，不应把端口直接暴露到公网。

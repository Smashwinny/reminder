# 拾遗

一款以颜色深浅呈现任务状态的轻量 Android 提醒应用。

## 第一版功能

- 粘贴或输入内容，立即记录任务
- 新任务为深红色；每次查看按 1～4 级渐近变淡，不会一次跳成蓝色
- 7 天未查看开始逐渐变黄，30 天显示蛛网落灰提示；再次点击会恢复红色提醒
- 按颜色、创建时间、提醒时间排序
- 设置系统通知提醒
- 完成、恢复与删除任务
- 已完成任务独立收纳，支持按任务正文和摘要关键词搜索
- 可给任务添加手机本地图片或视频附件
- 使用本地 SharedPreferences 持久保存，重启应用不会丢失
- 通过电脑端公网 HTTPS 入口跨网络双向同步
- 配置一次后自动同步，并显示上次同步时间
- 手机重启或应用升级后自动恢复尚未触发的提醒
- 电脑端任务数据每日备份，保留最近 14 天

## 多用户云端同步

2.0 版本使用邀请码注册和账号登录，不再使用全局六位同步码。手机和网页登录同一账号后自动同步，不同用户的数据由后端强制隔离。独立容器部署、旧数据迁移、备份恢复和更换服务器流程见 [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)。

以下命令仅用于迁移前的旧个人版，不应作为多人服务继续开放：

```bash
reminder internet
```

旧命令会启动本地个人数据服务。正式云端必须使用 `deploy/docker-compose.yml`，不得把旧六位同步码入口提供给朋友。

让电脑每次登录后自动恢复同步服务：

```bash
reminder install-autostart
```

数据恢复命令：

```bash
reminder backup
reminder backups
reminder restore sync-server/data/backups/某个备份.json
```

当任务内容只有一个 `http://` 或 `https://` 链接时，电脑同步端会自动读取公开网页，并使用 Kimi K3 生成中文标题和摘要。处理完成后在手机点击“仅接收”即可看到摘要。

点击任务会先打开完整详情卡片；阅读后颜色以动画渐变更新，当前列表位置保持不变。按颜色产生的新顺序会在下次打开页面时应用，避免正在阅读的任务突然跳走。

图片和视频通过 Android 系统文档选择器保存持久读取引用，媒体本体仍在手机相册或文件目录，
不会塞进任务 JSON。任务文字和附件名称可以同步，但媒体文件暂不跨设备复制；原文件被移动或删除后，
附件入口会失效。

## 构建

```bash
./gradlew assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`
